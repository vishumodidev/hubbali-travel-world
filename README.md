# Hubbali Travel World 🌍

Premier tour operators and verified tourist cab & tempo traveler rental service based in Hubballi, Karnataka.

## ✨ Features
- **All 31 Karnataka Districts Covered**: Comprehensive travel and taxi services across every district in Karnataka.
- **Fixed & Transparent Per-Km Vehicle Pricing**:
  - **Sedan (1 to 4 People)**: Rs. 12 / Km (Swift Dzire, Toyota Etios, Hyundai Aura)
  - **7-Seater (5 to 7 People)**: Rs. 15 / Km (Maruti Ertiga, Kia Carens, Toyota Rumion)
  - **8-Seater (Up to 8 People)**: Rs. 18 / Km (Toyota Innova Crysta, Mahindra Marazzo)
  - **Luxury Tempo Traveler (9+ People)**: Rs. 22 / Km (Force Urbania, 12/17/26 Seater)
- **Cultural & Pilgrimage Tour Packages**:
  - Hampi UNESCO World Heritage & Sacred Ruins (3D/2N)
  - Murudeshwar & Gokarna Divine Coastal Pilgrimage (3D/2N)
  - Grand South India Sacred Circuit & Statue Trail (5D/4N)
  - Sacred Tungabhadra & Kishkindha Heritage Trail (2D/1N)
- **Interactive Photo Gallery & Full-Screen Lightbox**: Real photography of Karnataka heritage, coracle safaris, and vehicle fleet.
- **Instant WhatsApp Booking & Estimator**: Auto-calculates tariffs and generates pre-filled WhatsApp booking itineraries.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
